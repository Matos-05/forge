# FORGE

Application web installable (PWA) de suivi de transformation physique : séances de musculation, repas, liste de courses et mesures.

- Fonctionne hors connexion : les données sont stockées sur le téléphone.
- Se synchronise avec un Worker Cloudflare et une base D1 quand le réseau est disponible, grâce à un code secret saisi dans l'app.
- Ce dépôt ne contient aucune donnée personnelle.

Installation sur iPhone : ouvrir l'app dans Safari, puis Partager → « Sur l'écran d'accueil ».
